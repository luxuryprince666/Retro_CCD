КАК ПОЛУЧИТЬ ГОТОВЫЙ APK ЧЕРЕЗ ОБЛАЧНУЮ СБОРКУ

В этом проекте уже настроен GitHub Actions workflow:
.github/workflows/android-apk.yml

Он автоматически собирает app-debug.apk при отправке исходников в ветку main/master. Он также запускается вручную из GitHub Actions -> Build RetroCCD APK -> Run workflow.

Для облачной сборки нужен авторизованный GitHub-репозиторий. В текущей среде нет Android SDK, Gradle, доступа к сети или подключённой GitHub-учётной записи, поэтому я не могу сам отправить исходники и скачать результат.

После подключения GitHub в ChatGPT я смогу продолжить с публикацией проекта и запуском workflow. В репозиторий нужно загрузить всю папку RetroCCD, не только .kt-файлы.

После успешной сборки APK будет доступен на странице репозитория:
Actions -> Build RetroCCD APK -> последний успешный запуск -> Artifacts -> RetroCCD-debug-APK

Внутри архива будет app-debug.apk. Это debug-подпись: она подходит для установки и тестирования, но не является production signing key для публикации в Google Play.
